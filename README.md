## Develop
Requirements and changes are managed with [OpenSpec](https://github.com/Fission-AI/OpenSpec) in `openspec/`.
This project is built from the [my-work-ai-builds](https://github.com/stevenbiss/my-work-ai-builds) workspace. Open Claude Code at the workspace root and run `/opsx:propose`, then `/opsx:apply`.

```bash
npm install
npm test
```
